# SIKLINK website

A Next.js starter for the SIKLINK agency website.

## Run locally

1. Install Node.js if it is not already installed.
2. Open this folder in VS Code.
3. In the VS Code terminal, run `npm install` once, then `npm run dev`.
4. Open the local address printed in the terminal (usually http://localhost:3000).

The main page is in `app/page.tsx`, its styling is in `app/globals.css`, and the supplied logo is in `public/siklink-logo.jpeg`.

The work cards are visual examples of service capabilities rather than confirmed client projects. The contact link uses the email shown in the supplied design reference; replace it if needed.
